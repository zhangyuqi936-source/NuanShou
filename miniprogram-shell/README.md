# 小程序壳（web-view 方案）

这是一个**最小微信小程序壳工程**，用于在黑客松现场把 H5 原型“装进小程序里”展示。

## 为什么这样做

- 不重写 UI：避免两套前端互相拖累
- H5 作为唯一真源：改一次，展示处处同步
- 现场更稳：用小程序入口 + web-view 打开，扫码体验更像产品

## 怎么用

1. 把 H5 部署到公网（任意静态托管）
2. 修改 `pages/webview/webview.js` 里的 `url`
3. 用微信开发者工具打开此目录预览

> 也可以通过路由参数覆盖：
> `/pages/webview/webview?url=<encodeURIComponent(你的URL)>`

## 注意

- 微信 web-view 只能加载**HTTPS**
- 域名需在小程序后台配置“业务域名”（黑客松可用临时方案/团队账号）
