# 暖守 NuanShou

> 独居女性经期应急守护 | 黑客松赛道：第四夜·一个人的时区

---

## 一句话

**痛到动不了时，一键启动 AI 主动应急：买药/叫车/挂号/通知联系人，并在失败时自动降级兜底。**

---

## 这个仓库有什么（双版本，互不干扰）

- `h5/`：核心原型（唯一真源，所有交互/演示以这里为准）
  - `h5/index.html`
  - `h5/overview.md`

- `miniprogram-shell/`：微信小程序“壳”（可选备份）
  - 仅用于把 H5 通过 `<web-view>` 方式承载成小程序形态
  - 不重写 UI，保证黑客松演示稳定

---

## 快速体验

### 方式 A：直接打开 H5（推荐）

1. 打开 `h5/index.html`
2. 首页点击 SOS 按钮 → 弹出帮助面板
3. 点 **「好的，交给你了」** → 进入「守护进度」页
4. 双击 **「· Demo」** → 循环演示 AI 服务降级（买药/医院/叫车失败的兜底方案）

### 方式 B：作为小程序展示（备份方案）

1. 将 `h5/index.html` 部署到公网（Vercel / GitHub Pages / 任意静态托管）
2. 在 `miniprogram-shell/` 中把 web-view 指向该 URL
3. 用微信开发者工具预览/真机扫码体验

## Demo 展示重点（评委关心）

- **解决什么问题**：独居女性经期突发不适、低能量状态下无法完成买药/就医/求助等一系列操作
- **怎么解决**：AI 作为执行者并行代办 + 安全联系人网络兜底（线下确认、弱连接、平时零互动）
- **完成到什么程度**：核心链路可展示、可解释、可体验；包含降级策略与解释性文案
