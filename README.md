# 暖守 NuanShou

> 独居女性经期应急守护 | 第四夜·一个人的时区

---

## 一句话

**疼到动不了时，一键让 AI 替你买药、叫车、挂号，同时通知最近的安全联系人过来。**

---

## 产品逻辑

| 层 | 能力 | 说明 |
|---|---|---|
| AI 执行管道 | 并行处理买药 💊 / 叫车 🚖 / 挂号 📅 | 用户在低能量状态下只需按一次 |
| 安全联系人兜底 | AI 失败时自动降级通知联系人 | 线下扫码建立弱连接，平时零互动 |
| 健康仪表盘 | 模糊库存 + 经期日历 | 不用精确计数，系统智能推算 |

---

## 技术栈

- 纯 HTML5 + CSS3 + JavaScript（零依赖）
- 适配小程序 WebView，可直嵌
- 后端预留 API 接口（待接入地图/外卖/网约车 SDK）

---

## 赛道匹配

**第四夜｜一个人的时区**

> "一个人生活最难的时刻，常常不是发生大事的时候，而是所有小事刚好都没有人接住的时候。"

暖守不是在事情发生后报警——而是在事情发生**那一刻**就开始解决。
